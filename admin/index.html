Erişim anahtarı nasıl alınır?
  1. GitHub'da Fine-grained token oluştur sayfasını açın.
  2. Repository access → Only select repositories → menü deposunu seçin.
  3. Permissions → Contents → Read and write yapın.
  4. Oluşturun ve github_pat_ ile başlayan anahtarı buraya yapıştırın.

Anahtar sadece bu tarayıcıda saklanır, başka hiçbir yere gönderilmez (yalnızca GitHub'a).
